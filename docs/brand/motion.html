Sakina · motion language

Everyone else moves things.
We light them.

Three primitives, all derived from one fact about our own mark: a chorkhona is not a shape, it is an opening that lets light into a house. That gives us a vocabulary no other messenger is using, and it costs a cheap phone almost nothing.

Replaces the tick popping in. The bubble does not move at all — which is the whole point of an app named for stillness.

Why this is not a shimmer

A loading shimmer loops while you wait, and the design-tells catalogue is right that it is a cliché when used as decoration. This is its semantic opposite: it runs once, on success, and never while waiting. Seeing it means something arrived. If it looped it would mean nothing, and we would have built the tell instead of avoiding it.

Where it fires: a message acked, a receipt read, an upload finished, a channel joined.

Alternating, not looping: a sawtooth snaps back to dim at the top of each cycle, and that snap is exactly the flashing this avoids.

A spinner is an object that is not the thing you care about, placed next to the thing you care about, moving. Breathing lets the message itself say it has not landed — which is one fewer element on screen and one less thing competing with the conversation.

Where it applies: a pending message, an upload in flight, a skeleton block.

3 · ЧАРХ — the turn

The mark rotates 45° and holds. Eight discrete positions, never a smooth spin.

The mark has four-fold symmetry, so a smooth spin would look almost static. Stepping makes it visibly turn, and the silhouette alternates square and diamond on every step.

Every loading indicator in the world spins smoothly. Ours steps, because our mark is squares set at 45° to each other and a 45° step is the smallest rotation that returns the shape to a face. It reads as deliberate rather than anxious, which is the difference between a spinner and a clock.

Used only where there is no object to breathe: app-level loading, and a refresh already in flight.

The rule that keeps it a system

One meaning per primitive, and light is only ever for truth. The moment ТОБ is used for decoration — a flourish on a button, a sweep on a card because the screen felt flat — it stops meaning "delivered" and the whole vocabulary is worth nothing. That is the same discipline the palette already has: one accent, and saffron only for rare warmth.

What this deliberately is not

Telegram's springsElastic overshoot and bouncing bubbles. Ruled out by brand rule 3 before this document existed — motion settles, never bounces — and it is the single most recognisable thing about their motion, so borrowing it reads as imitation rather than influence.
Particles and confettiReaction explosions, celebration bursts. Expensive on the target phone, loud by definition, and the opposite of an app named for stillness.
A sparkle on anythingTell A11 in the catalogue: the universal shorthand for "AI feature", now pure noise. Our light is a straight band at a fixed angle, with no star, no twinkle, and no glow.
Looping shimmer as decorationThe tell that ТОБ is most likely to be mistaken for. Ours fires once on success and never while waiting, which is the opposite meaning.
Randomised jitterGuardrail G17. Nothing here is randomised — the stepping angles are fixed, the stagger is derived from row position, and the skeleton's varied widths come from a fixed pattern.
Smooth spinnersNot wrong, just nobody's. A four-fold symmetric mark spinning smoothly looks static, so the honest choice was either a different indicator or a different rotation. We changed the rotation.

Reduce motion

Try the toggle at the top. Every primitive has a path that removes it, not one that shortens it — guardrail G2 is explicit that those are different things, and pnpm test:motion fails the build if an animation is added without one.

  • ТОБ — does not run. The tick simply appears; the information was never in the motion.
  • НАФАС — the object holds a single dimmed opacity, so "waiting" is still legible without anything moving.
  • ЧАРХ — the mark stands still and a text label carries the state instead, because a loading indicator that neither moves nor says anything is not an indicator.
The bit that is easy to get wrong

Reduced motion is not reduced information. Each fallback above still says the same thing; it just stops saying it with movement. A fallback that removes the meaning along with the animation is a worse bug than the animation was.
